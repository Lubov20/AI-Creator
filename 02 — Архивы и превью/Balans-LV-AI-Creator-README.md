# Balans LV — AI Creator

Новая самостоятельная версия: https://balans-lv-immersive.dapper-loon-8707.chatgpt.site
Предыдущая сохранена: https://balans-lv.dapper-loon-8707.chatgpt.site

Локальный запуск: распаковать исходники и запустить любой статический HTTP-сервер в папке с index.html. Например: python -m http.server 8000. Открыть http://localhost:8000. Открытие HTML напрямую через file:// не поддерживает загрузку модулей.

В новой версии:
- Three.js / WebGL, объёмные цифры с фасками, отражающие материалы и хромированная скульптура.
- Искажение и хроматическое расхождение возле указателя.
- Галерея из шести демонстрационных работ на вращающейся оси, частицы и световые кольца.
- Колесо мыши управляет вращением галереи. Есть стрелки, перетаскивание и доступный список.
- Откройте работу и прокручивайте над изображением: изгиб переходит в разлёт частиц. Обратная прокрутка собирает картинку обратно. Дальнейшая прокрутка после полного распада возвращает в галерею.
- Окно тоннеля разворачивается на весь экран по мере прокрутки; скорость погружения связана с прогрессом секции.
- Поддержаны клавиатура, Escape, сенсорный ввод и prefers-reduced-motion.

Сайт ориентирован на AI-креатора. Все работы — явно помеченные демонстрационные заглушки. Обложки процедурные, не являются реальными кейсами Любови. Контактная форма копирует обращение; отправка не настроена до предоставления контактов.

Проверено в браузере: WebGL без ошибок; открытие работы; распад и обратное восстановление при прокрутке; галерея; полноэкранный тоннель; ширина 390px через браузерный iframe. Производительность на физических телефонах не измерялась.

Референсы: Lusion (видеозаписи пользователя); Active Theory / Welcome to Hogwarts. Это авторская интерпретация эффектов, не точная копия их сцен или кода. Three.js 0.170.0 поставляется локально с MIT-лицензией. Шрифт Manrope загружается через Google Fonts с системным fallback.
